# Архитектура MiniGames Center

- Корень: каталог игр.
- assets/css/portal.css: стили каталога.
- assets/js/portal.js: логика каталога.
- games/kingdom/: независимые HTML, CSS, JS первой игры.
- games/last-hero/: независимые HTML, CSS, JS второй игры.

## Правила

1. Не добавлять игровой JavaScript и CSS непосредственно в HTML.
2. Не изменять другие игры при доработке одной.
3. Все игровые страницы работают как статический сайт без сервера.
4. Локальные сохранения используют уникальные ключи каждой игры.
5. Сначала записывать вспомогательные файлы, затем менять ссылки в HTML.
6. Проверять ссылки, загрузку скриптов и консоль браузера перед выпуском.
7. Держать интерфейс и пользовательские сообщения на русском.
8. Новая игра: games/<slug>/index.html, styles.css и game.js.
