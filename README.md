# MiniGames Center

Браузерная площадка 12 мини-игр. Все пользовательские интерфейсы на русском.

## Структура

```text
index.html                 Главная страница
assets/css/portal.css      Стили каталога
assets/js/portal.js        Логика каталога
games/kingdom/index.html   Королевство с нуля
games/kingdom/styles.css   Стили игры №1
games/kingdom/game.js      Логика игры №1
games/last-hero/index.html Заготовка игры №2
games/last-hero/styles.css Стили игры №2
games/last-hero/game.js    Заготовка логики игры №2
docs/ARCHITECTURE.md      Правила архитектуры
```

## Публикация

GitHub Pages: ветка `main`, папка `/` (root).

Площадка: https://koraevgog-create.github.io/minigames-center/

## Статусы

1. «Королевство с нуля» — рабочая версия 0.4, реорганизована без изменения логики.
2. «Последний герой» — создана отдельная структура; игровой процесс ещё не перенесён и не опубликован как готовый.
3–12. Остальные игры — в плане.

## Правила разработки

См. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Новые игры не должны затрагивать код существующих. Перед каждым релизом проверяем корректность ссылок, запуск и интерфейс на ПК и телефоне.

## Дальше

Реализовать игровой цикл «Последнего героя» и открыть кнопку «Играть» в каталоге только после проверки.
