# MiniGames Center

Русскоязычная браузерная площадка из 12 постепенно развиваемых мини-игр.

## Запуск

Статический сайт: откройте `index.html` или включите GitHub Pages → Deploy from a branch → `main` → `/ (root)`.

Первая игра: [Королевство с нуля](games/kingdom/index.html), версия 0.3.3. Сохранения работают в localStorage браузера.

## Запланированные игры

1. Королевство с нуля — первая играбельная версия
2. Последний герой
3. Легенды семи королевств
4. Осада крепости
5. Подземелья проклятых
6. Война империй
7. Бизнес-империя
8. Последнее убежище
9. Колонизатор галактики
10. Железнодорожный магнат
11. Уличные гонки
12. Ферма мечты

## Структура

- `index.html` — главная страница и каталог.
- `games/kingdom/index.html` — первая игра.
- `games/<game-id>/` — отдельная папка для каждой следующей игры.

Каждая игра развивается независимо, поэтому можно переключаться между проектами без затрагивания остальных.
